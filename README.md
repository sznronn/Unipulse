## 💡 Overview

Students often face fragmented tools for campus engagement—study notes are scattered across various drives, tech event announcements get buried in chat groups, and important deadlines get missed. 

The **Student Resource & Event Hub** solves this by unifying academic material sharing, event management (focusing heavily on student-led Tech Events like Hackathons and Workshops), and dynamic in-app alerts into a single, cohesive dashboard.

---

## ✨ Key Features

* 📚 **Academic Learning Repository:**
  * Categorized file hub searchable by Course Code, Department, and Topic Tags.
  * Interactive "Upload Material" modal for contributing lecture notes and study guides.
  * Community upvoting and bookmarking system for high-quality notes.

* 🚀 **Campus & Tech Events Board:**
  * Event cards tailored for Hackathons, Developer Workshops, Coding Contests, and Club Meetups.
  * Interactive RSVP toggle with real-time attendee counter updates.
  * Event creation modal to submit new campus activities.

* 🔔 **In-App Notification Center:**
  * Real-time notification drawer with unread badge counters.
  * Instant feedback when RSVPing to events or uploading resources.
  * "Mark all as read" and alert category filtering.

* 🌓 **Modern UI/UX:**
  * Mobile-responsive layout with clean sidebar navigation.
  * Dark / Light mode toggle.
  * Quick-stats overview dashboard.
